**Offline-first academic tracker built for AUST CSE students.**

---

### Features

* **Attendance Tracker:** Real-time threshold monitor and 14-week class logger so you always know where you stand.
* **CGPA & Mark Evaluator:** Calculate semester/overall CGPA and evaluate required final marks on the fly.
* **Full Curriculum Guide:** Complete AUST CSE syllabus reference covering all semesters up to 4th year.
* **100% Offline:** Works without an internet connection, all data stays locally on your device.

---

### Installation

1. Download **`Bunkr-v1.0.0.apk`** from the [Latest Release](https://github.com/mushfiq-dev/bunkr-app/releases/latest).
2. Open the downloaded file on your Android device.
3. If prompted, enable **Install from Unknown Sources** for your browser or file manager.

---

### Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Native Runtime:** Capacitor (Android)
